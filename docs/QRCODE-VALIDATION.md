# 二维码生成器

2026-11-09，本地开发验证；未创建新版本标签或发布 Release。

第十二项内置工具，Dock 搜索支持二维码、ewm、qr、qrcode；工具库可打开和停用。文字与网址完全在本机编码，无请求、URL 访问或上传。使用 qrcode 1.5.4；最大输入 2331 UTF-8 字节（更高容错可能提前达到容量），空输入或错误立即移除旧二维码并禁用导出。提供 L/M/Q/H 容错及 256/512/1024 尺寸。

保持黑白对比和四模块白边。PNG 按整数模块绘制，实际尺寸不超过所选值，防止重采样影响扫描；SVG 使用完整矩阵与所选尺寸，输入不插入 SVG 标记。复制按钮复制 SVG 源码。桌面版 PNG/SVG 通过 Wails 原生保存对话框选择路径，取消不报成功；浏览器预览使用下载。遵循保存对话框返回路径，避免修改后缀绕过已有文件覆盖确认。

沿用工具会话：Dock 临时保留输入及参数，独立窗口自动保存到 tool-windows/qrcode.json，Esc 保存关闭，正常退出与重启恢复。五种语言沿用共享词典，深浅主题中二维码始终黑白。

验证：

- 35 个 Vitest 测试通过。jsQR 独立解码器验证 URL、中文、Emoji、多行/尾空格及长数字，覆盖四容错级别；UTF-8 与高容错容量边界测试通过。
- 27 个 Playwright 场景全量通过；后续预览尺寸修正后重新运行两项 QR 专项通过。实际下载 PNG 解码与输入相同，SVG 尺寸、复制、搜索、清空、错误清除旧图、选项保留及独立窗口关闭重开通过。
- macOS Go race 全量通过。隔离原生 Wails/WebKit 探针沿生产服务和前端验证 QR 输入自动保存、Dock 隐藏不影响独立工具、窗口复用、原生菜单与窗口语言切换、正常退出及第二进程恢复；不触碰用户数据或运行进程。
- 本机 arm64 .app 构建及 codesign verify 通过。Windows/Linux amd64/arm64 交叉编译通过；这些目标未做本轮实机 GUI 验收。
- 默认 960×660 浏览器深浅截图已目视检查，预览完整显示，无裁切。二维码导出内容已解码验证，但原生保存对话框手动交互及真实手机摄像头扫描未在本轮验收。
