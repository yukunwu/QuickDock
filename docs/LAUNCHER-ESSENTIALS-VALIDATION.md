# 启动器增强与开发工具

2026-11-20，本地开发验证，分支 `feat/launcher-essentials`；未创建新版本标签或发布 Release。

本轮新增：开机自启动、搜索关键词（`{query}` 网址）、结果次级操作（`⌘↵`／`Ctrl+↵`）、剪贴板历史（默认关闭）、文件搜索（`f 名称`）、配置导入导出，以及正则测试、JWT 解码、颜色转换、进制转换、文本对比、Cron 表达式六个工具。内置工具由十三类增至二十类，五种界面语言同步补齐。

验证：

- 57 个 Vitest 测试通过。新增覆盖：关键词 URL 规范化与转义、域名中占位符拒绝、关键词优先于句子翻译；剪贴板排序与搜索；正则分组／替换／零宽匹配；JWT Base64URL、大整数、过期判断与 JWE 拒绝；颜色 HEX／rgb／hsl 解析、OKLCH 已知值与 WCAG 对比度；BigInt 进制与前缀歧义；文本对比 300 轮随机输入校验可还原两侧文本且编辑数等于 LCS 最小值；Cron 名称、步长、Vixie 日期／星期规则、UTC 跨周末与“2 月 30 日永不运行”。
- 40 个 Playwright 场景全量通过（本地 Chrome）。新增：六个工具的交互；正则灾难性回溯在 V8 中由 Worker 3 秒超时中止；关键词 Tab 补全、搜索行选中与打开地址；剪贴板开启前不记录、开启后记录 QuickDock 复制并可固定；配置导出文件不含使用记录，导入后常用网址与世界时钟还原。
- Go `-race` 全量通过。新增：XDG autostart `Exec` 引号转义、剪贴板去重／固定保留／条数与字节上限／损坏文件拒绝覆盖、固定上限 50、清空保留固定项、关键词 URL 转义、配置文件校验、文件结果排序与缓存目录过滤。
- 原生探针 `scripts/test-native-launcher-essentials.sh`（隔离设置，与已安装的 QuickDock 并行运行，不打开文件、不登记登录项）在本机通过：剪贴板关闭时与开启前已有内容均不记录；`pbcopy` 文本一个轮询周期内记录；`org.nspasteboard.ConcealedType` 内容跳过；重复复制只移到最前；写回条目后 `pbpaste` 一致；Spotlight 搜索 `quickdock` 约 1.1 秒返回 6 项且无 `~/Library` 或隐藏目录；不在最近搜索结果中的路径拒绝打开；正则工具在 WebKit Worker 中运行。脚本运行前快照全部剪贴板类型（含 HTML），结束后按原样恢复。
- WebKit 的正则引擎在回溯上限处直接返回“无匹配”，不会卡住；V8（Chrome 预览、Windows WebView2）依赖 Worker 超时。两种结果探针均接受。
- 本机 arm64 `.app` 构建及 `codesign --verify` 通过。Windows／Linux amd64 交叉编译通过。
- 浏览器预览截图已目视检查（正则、JWT、颜色、进制、文本对比、Cron、剪贴板空状态与列表、关键词搜索），无裁切或重叠。
