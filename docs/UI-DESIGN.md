# QuickDock UI · 0.1

以下为 2026-11-04 会话内用户最终确认的界面与交互，覆盖交接时的大窗口启动器原型。

## 默认启动器

用户以 uTools 最近使用网格为参考，要求默认唤起进入小面板。采用 780×340 的 macOS 风格窗口：顶部 66px 搜索栏和设置按钮，下方两行八列应用／工具图标，底部提供全部工具和简要键盘提示。展开时增高到 520px，更多项目可滚动查看。

空搜索按使用记录排序，没有使用记录时优先展示 Finder、常用浏览器、编辑器、终端等常见应用。输入后切换到紧凑结果列表，显示应用、工具、网址或算式结果。应用名称增大至 12px / 600，结果名称 14px / 600，兼顾可读性与网格密度。

使用系统 sans-serif 和 SF Mono，系统灰背景、系统蓝强调色、细边框和 AppKit 标准圆角；支持浅色、深色、跟随系统。真实原生应用图标由系统读取，无外部字体／图片请求。

## 设置和工具库

进入设置或工具库后展开至 960×660，左侧保留轻量导航。设置使用 macOS 分组卡片，包含外观、全局快捷键、索引状态与刷新、十类工具启停、网址管理。工具库提供开发／日常分类和搜索。

## 工具工作区

打开工具后独占 960×660 窗口：**不渲染 QuickDock 的侧栏、顶部导航和底栏**。仅保留工具自身的返回、标题、复制等操作和编辑区域。根据工具展示对应选项；常规转换为输入／结果双栏，UUID 为单输出区，网址为编辑表单与列表。错误显示在结果区域，输入和选项在本次会话保留。

大文本结果只预览前 65,536 字符，状态栏明确提示“复制获取全文”；复制保留完整内容。工具选项区提供“清空输入”。处理中显示状态并暂时禁用复制，避免复制过时结果。隐藏后保留草稿、释放派生结果；重负载会话闲置回收后再次进入会重新计算。

## 键盘、窗口与多屏

- Option+Space 默认为全局显示／隐藏切换，可更改。隐藏保留当前工具和输入。
- 每次显示按鼠标所在屏幕定位，在该屏幕的可用区域居中并限制边界；使用 Cocoa points 适配混合 DPI，避开菜单栏和 Dock。
- 展开工作区时继续留在当前屏幕。
- 空搜索网格四方向选择；结果列表上下选择；Enter 执行。输入法组合中不处理执行键，兼顾 Safari 的 keyCode 229。
- Esc 在工具页返回、设置／工具库回启动器、启动器隐藏；⌘ W 隐藏；⌘ , 打开设置。
- 搜索页失焦隐藏；工具与设置失焦保留；关闭事件只隐藏，菜单栏退出才结束进程。
- 再次启动唤起原实例，不创建第二个常驻进程。

## 状态与反馈

浏览器预览明确显示“示例应用”，启动本机应用会报错；原生显示真实应用。快捷键冲突显示可操作错误并保留原绑定。索引中、局部读取失败、设置保存失败、复制失败均有反馈。非关键索引警告放在设置中，避免占用小面板。

## 2026-11-04 Dock联网快捷入口与计算稿纸

用户进一步明确：搜索和翻译从Dock输入直接触发，不转入完整工具页。应用零匹配且输入非空时，在已有工具／计算匹配后显示Google搜索与翻译两行快捷入口，支持方向键／回车与点击；有应用匹配时不显示这两项。

- 搜索：直接按完整原文构造Google网页搜索URL，用默认浏览器打开，不嵌入或抓取搜索结果、不持久保存关键词。
- 翻译：在原780px宽Dock中展示紧凑翻译面板（高度520px），保持顶部搜索框；默认MyMemory，初始中／英语言按输入提示设置，可手动切换语言；Google源支持自动检测、交换、复制、重试或返回。点击翻译快捷项才联网，输入变化取消旧请求并清除旧译文，需再次点击翻译；不自动上传后续键入内容。显示当前翻译源、在线传输说明与加载／错误状态。
- 计算稿纸：替换原计算器显示名，ID继续calculator，旧关键词／启停配置兼容。独占工具页左侧多行稿纸、右侧逐行结果；一行一个算式，支持#备注和ans引用上一行结果，错误按行呈现。⌘Enter／保存记录保存本张稿纸；工具内部历史抽屉支持倒序查看、载入、删除和清空（本页确认）。最多100份、编码总量约8MiB，每份200行／20000字符。未保存草稿在隐藏及内存回收后恢复。
- 历史写入独立版本化原子JSON，损坏／未来版本禁止覆盖；写入失败保留稿纸并报错。浏览器预览使用独立localStorage。空稿或有错误不入历史。
- 在线入口设置可单独启停；工具库维持10项。全局文案不得再声称所有功能均离线。


实际网络验证：本机Google公共翻译接口返回429；MyMemory原生Go请求成功，故默认MyMemory（单次500 UTF-8字节），Google可选（5000字符）。不静默切换翻译源，不预先上传输入。HTTP客户端优先环境代理，再读取macOS系统静态代理／排除规则；PAC暂不支持，失败明确返回错误。翻译请求可取消、有超时及响应大小上限。

新增截图：`08-online-shortcuts.png`、`09-dock-translation.png`、`10-calculation-notebook.png`。在线截图使用可重复的测试响应；真实网络结果另见验证记录。

翻译面板参与重负载后的闲置内存回收；当前语言和已完成译文只在本次会话内恢复，不自动再次联网。

## 2026-11-05 光标与翻译错误修正

计算稿纸使用16px等宽字体、24px行高；稿纸横线、结果行和错误行共用同一行高，避免原36px行高把输入光标拉得过长。保留原生textarea的中文输入、选择和键盘编辑行为。

翻译失败隐藏运行时异常前缀，Google 429明确标注来源及限流。Google失败后提供“切换到 MyMemory”，只切换源并提示确认语言，不自动发送；超过500 UTF-8字节时禁用切换按钮并提示缩短原文。请求进行中阻止重复提交，仍可通过修改文本／语言取消。

## 2026-11-05 独立翻译与工具窗口

翻译加入工具库（现在11项工具，另有Google搜索入口），搜索“翻译／fy”可直接打开空白翻译页，在左侧多行输入、右侧显示译文；⌘Enter或翻译按钮发送。初始空白页按中英文字提示语言，手动选定后保留用户选择；恢复已保存页面不自动翻译。原Dock无应用匹配的翻译快捷入口继续保留。

工具页和Dock翻译提供“独立窗口”，首次弹出携带当前输入；工具库卡片另有“独立打开”，恢复该工具上次独立保存的内容。菜单栏可直接“打开翻译窗口”。每个工具复用一个原生窗口，使用标准macOS标题栏，可移动、缩放、最小化。失焦不隐藏，Dock快捷键只控制原Dock。窗口内部没有QuickDock侧栏或导航菜单。

独立窗口内容、选项及翻译结果自动保存在本机；窗口位置／大小及正常退出时尚未关闭的窗口在下次启动恢复。关闭窗口前等待保存；显式关闭的窗口不会下次自动弹出，但可从工具库独立打开恢复内容。正常退出也等待各页保存，写入失败保留窗口并显示错误。底部显示正在保存／已保存／保存失败。每个工具最多8MiB序列化草稿，计算历史仍独立保存。

独立工具文件位于应用数据目录`tool-windows/<工具ID>.json`，版本化、0600权限、原子写；损坏／不支持的版本不覆盖。拖动缩放合并写入，避免每个原生事件重复写大文件。Dock内临时工具会话继续沿用原机制。独立窗口关闭会销毁其WebView；不会将未使用的全部工具预先建窗。

## 2026-11-05 翻译结果检查

MyMemory包含社区翻译语料，面板提示核对译文。若目标为英语等拉丁文字语言，却收到纯中文等明显不符合的文字，先检查完全匹配且语言一致的候选；无合格候选时明确拦截并禁用复制。此检查仅针对明显文字冲突，不作为语义正确性的保证。旧版MyMemory缓存译文不再恢复显示，保留原文与语言，需再次点击翻译；不会自动联网。

## 2026-11-05 Google网页翻译替换API界面

按用户新要求，翻译切换为内嵌Google官方网页，覆盖前述MyMemory默认源及源选择UI。使用独立原生WKWebView直接加载页面；Dock快捷项／独立工具页继续提供，Google页面内输入并显示译文。工具栏保留返回、独立窗口、重新加载、浏览器打开。Dock顶部修改内容后点击翻译输入／Enter才重新交给Google。独立页面原文与语言保存恢复，当前译文由网页重新生成；页面本身仍可能要求验证。详见GOOGLE-WEB-VALIDATION.md。
