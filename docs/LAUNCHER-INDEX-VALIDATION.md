# 自动索引与重新唤起

2026-11-09，本地修复。保留本轮尚未发布的二维码功能。

## 自动应用索引

旧行为仅在启动、菜单或设置刷新。新增后台单例监控：每3秒检查目录与入口元数据，变化才调用各平台既有扫描器并提取图标；唤起时立即发起检查。5分钟兜底扫描覆盖未反映在入口目录的变化。检查本机平均1.61ms（10次），不是每3秒全量读取图标。

macOS监视/扫描使用同一组根路径，包括用户Applications；.app是叶子，监控只额外stat Contents/Info.plist、MacOS/Resources目录，避免读取每个.app全部内容。可发现新建目录、移动、删除、改名及分阶段复制元数据。Linux复用XDG/Flatpak/Snap入口；Windows检查用户/系统开始菜单和桌面快捷方式。Windows仅商店注册变化等无快捷方式的情况由5分钟兜底处理。

扫描串行，扫描期间新的变化合并为后续一轮，不能因indexing=true直接丢弃。后台完成后向主前端发送quickdock-apps-changed，当前搜索保留并立即更新结果；不依赖重新聚焦或点击刷新。正常退出停止监控。

## Dock交互

所有实际Hide路径（快捷键、Esc、关闭、失焦、启动应用）统一发送原生隐藏事件。隐藏同步清空query/选择/展开/翻译，回launch并卸载主工具；原生窗口回780×340且取消编辑态。再次唤起聚焦空搜索，重置输入法组合标记。浏览器visibilitychange或普通focus不视为关闭，不清工具输入。工具DraftMap、计算历史和独立窗口未删除；大输入隐藏回收与恢复仍有回归。
